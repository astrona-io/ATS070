# Understand the Backstage framework

This section covers understand the Backstage framework. It develops framework Features, Integrations And Application Ownership through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain Backstage as an assembled developer portal framework.
- Distinguish catalog, templates and documentation responsibilities.
- Identify what remains the responsibility of the adopting organization.
