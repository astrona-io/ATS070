# Summary

Backstage provides a framework for integrating developer-facing capabilities around a software catalog. Catalog metadata, software templates and technical documentation support different tasks. Installed plugins and external systems determine the actual application behavior. The adopting organization owns feature selection, identity, permissions, operational support and user experience; installing the framework alone does not provide a complete production platform or guarantee accurate service information.
