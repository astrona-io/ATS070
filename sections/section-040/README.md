# Understand Backstage client-server architecture

This section covers understand Backstage client-server architecture. It develops browser APIs, Backend Routes And Trust Boundaries through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Trace a browser feature through its client API and backend route.
- Distinguish discovery, authentication and authorization responsibilities.
- Explain why privileged integrations belong behind server boundaries.
