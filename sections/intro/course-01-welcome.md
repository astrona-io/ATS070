# Welcome To The Course

This course is for learners preparing for the Certified Backstage Associate (CBA) examination. It covers Backstage Infrastructure, worth 22% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations in this course build the reasoning needed to choose an answer, and the hands-on labs let you see each mechanism work in a running Backstage application.

At the end, you can explain the Backstage framework, configure Backstage, deploy it to production and describe its client-server architecture. You can also change the configuration of a running Backstage deployment on Kubernetes and check the result. Technical terms and acronyms are defined when they appear. Examples use a portal named Starfleet Portal. The names identify examples only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts, and ends with a summary. Every module has a playground, which is a clean Kubernetes cluster with Backstage running that you can explore without any task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
