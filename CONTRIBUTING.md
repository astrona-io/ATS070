# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS070: Certified Backstage Associate (CBA), Backstage Infrastructure (22%), part of ATP014.

Preserve IDs, weights and existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Keep technical Markdown draft until review.

On 2026-11-03 the maintainer lifted the reading-only rule: every module has a playground and a graded lab, every section a capstone lab and a quiz. Labs are built untested; do not claim executed results. Quiz files are `quiz.yaml` per section and `sections/final-domain-quiz.yaml`; preserve stable question identities and per-option feedback.

Use primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Run `astrona validate -c` on every lab and playground when changing structure. Review Markdown and questions for semantic correctness as well as structure.
